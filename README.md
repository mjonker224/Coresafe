# CoreSafe Website V2

Static single-page CoreSafe website prepared for GitHub and Netlify.

## Files
- `index.html` — complete website, including embedded images, CSS and JavaScript.
- `netlify.toml` — Netlify publish configuration and basic security headers.

## Deploy on Netlify
1. Upload these files to the root of your GitHub repository.
2. In Netlify, create/import a site from the GitHub repository.
3. No build command is required.
4. Publish directory is `.` (repository root).

The site uses Netlify Forms markup for hosted form submissions.
