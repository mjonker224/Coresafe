# CoreSafe Website V18 — National SEO & Back to Top

Based on V17, with no visual layout changes other than one back-to-top control.

## Changes
- Bottom-right navy Back to Top button, appearing after scrolling 420px; orange on hover. It smoothly scrolls to the top.
- Nationwide SEO copy that describes supported services without claiming offices in every province.
- Descriptive title, meta description, Open Graph, canonical, ProfessionalService structured data, `robots.txt` and `sitemap.xml`.
- No pricing or unverified endorsements added.
- Preserves existing layout, font, colours, stock image links, animations, WhatsApp icon and quotation form.

## Preview
Open `CoreSafe_V18_Standalone_Preview.html` in Chrome or open `index.html` from the extracted folder. External gallery stock photos and Google Fonts still require internet access.

## Publish
Deploy the **contents** of the folder to the existing Netlify site at `coresafesa.netlify.app`. The SEO canonical and sitemap use this domain. If you use a different custom domain, change the canonical, og:url, JSON-LD URL and sitemap URL to that domain first.

After deployment, test a real Netlify form enquiry and confirm it appears under Netlify Forms; check Google Search Console ownership, submit the sitemap, and inspect indexing. SEO improvements do not guarantee rankings or traffic.
